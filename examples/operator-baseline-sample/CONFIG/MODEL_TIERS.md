# Model Tier Policy

## Tier 0
Cheap or free default for drafts, routing, classification, and repetitive low-stakes work.

## Tier 1
Routine paid fallback when Tier 0 degrades.

## Tier 2
Deeper analysis or final polish when the cheaper path failed for a named reason.

## Tier 3
Critical exception only. Explicit approval required.

## Escalation Rule
If you cannot name the failure condition that justifies escalation, do not escalate.
